# 观测记录的共享映射

目录中的现场会话全部使用合成记录。实际内核行为由本机同用户的临时进程、文件或连接提供。

## 现场数据

样本记录使用 4 字节网络序正文长度、UTF-8 正文和 4 字节网络序 CRC32。会话给定页大小、写入边界和报告时点。文件描述符可以映射指定范围，跨页范围中的实际字节可由不同进程读到。

`field-session.json` 中的 actions 带相对时点与原始操作名。同一时点的动作可能相遇，记录顺序用于重放输入。现场观测和业务请求均保留原始内容。

## 运行

使用 Linux 上的 Python 3.11 和标准库。运行 `python -m unittest discover -s tests -v` 检查会话和内核接口。运行 `python field_peer.py --probe` 可单独查看原始操作的观察值。临时进程和文件只在指定的联调范围中使用。

设备入口有三个参数，依次是父进程实际继承的文件描述符、字节偏移、字节数，打开只读映射后以十六进制返回当时读到的原始字节。探测通过两个进程读写同一 memfd。
